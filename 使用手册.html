🔐 密码退房后自动失效，每次入住密码不同

🏠 房东篇 — 管理后台

1. 登录后台

1打开 https://afei-chi.github.io/shuiquangou/admin.html
2输入管理密码：chengde2024
3勾选「保持登录」→ 点「进入后台」
💡 勾选保持登录后，下次打开直接进入，无需输密码

2. 首次配置（只需做一次）

1点击侧边栏 ⚙️ 全局设置
2粘贴 GitHub Token
3点「💾 保存Token」→ 再点「🚀 测试发布」
💡 Token只需配置一次，发布后其他手机/电脑打开管理端自动同步

3. 日常操作

📊 数据看板

首页看板显示景区、美食、路线数量，以及发布状态
点 🔄 同步 从线上拉取最新数据
点 🚀 发布 将修改推送到线上，客户端自动更新
⚠️ 修改内容后记得点「🚀 发布」才能生效！修改前先点「🔄 同步」避免覆盖线上数据！

🏯 景区管理

1点击「+ 添加景区」或点击已有景区的 ✏️ 编辑
2填写名称、分类、介绍等
3🖼️ 添加图片：粘贴图片URL 或 点击上传本地图片
4保存后回到看板 → 点「🚀 发布」

🍜 美食 / 📜 路线 / 💡 贴士

操作方式同上：编辑 → 保存 → 🚀 发布

🔐 门锁密码

1新客人入住前，点「🔄 生成新密码」
2填写住客姓名、入住/退房日期
3保存 → 🚀 发布

4. 手机桌面快捷方式

iPhoneSafari打开 → 底部分享按钮 →「添加到主屏幕」
AndroidChrome打开 → 右上角菜单 →「添加到主屏幕」
📱 添加到桌面后像App一样全屏打开
