🔴 BUG-001 | 严重 | 客户端与管理端默认数据不一致

影响用例：S01, C01-C32（全局影响）

问题描述：客户端 loadDB() 函数在 localStorage 为空时不保存默认数据，导致客户端和管理端各自使用独立的数据副本。客户端的默认数据包含8条美食+6个景区，而管理端默认数据仅2条美食+2个景区。当管理端先打开后保存了稀疏数据，客户端刷新后内容会大幅缩减。

根因：客户端 loadDB() 缺少 saveDB() 调用；两边的 getDefaultDB() 数据量不一致。

修复方案：① 客户端 loadDB 也保存默认数据；② 统一两端的 getDefaultDB 使用同一份完整数据源。

状态：🔧 待修复

🔴 BUG-002 | 严重 | 管理端路线编辑时添加天数/节点导致表单数据丢失

影响用例：A09, A10, E06, E07

问题描述：在路线编辑弹窗中填入名称、简介等字段后，点击"+ 添加一天"或"+ 添加节点"，整个弹窗被关闭再重新打开。重新打开时数据源来自 window._editingRoute 对象，但该对象在弹窗关闭前并未从DOM表单同步数据，导致用户已填写的字段全部丢失。

根因：addRouteDay() / addRouteItem() 在关闭弹窗前未收集当前表单值到 window._editingRoute。

修复方案：添加/删除天数/节点前，先从DOM收集所有表单字段值更新到 window._editingRoute，然后再关闭并重建弹窗。

状态：🔧 待修复

🟡 BUG-003 | 中等 | selectRoute 处理不存在路线类型时表现异常

影响用例：C08, C09, C13

问题描述：当 currentRouteType 在活跃路线列表中找不到匹配（如所有路线被隐藏，或 currentRouteType 指向了被删除的类型），selectRoute 函数仍然尝试设置Tab active状态但找不到对应按钮，导致所有Tab都取消active。route 为 undefined 时虽被 return 但内容区已经是空白的。

根因：缺少对 route 不存在的优雅降级处理，以及缺少对空列表的 fallback。

修复方案：如果当前类型找不到匹配路线，自动选中第一条可用路线；如果完全无路线，显示"暂无路线"提示。

状态：🔧 待修复

🟡 BUG-004 | 中等 | 天气温度可能出现 NaN

影响用例：C02

问题描述：updateWeather() 中当 DB.dailyTip.temp 为 undefined 且 fallback temp 变量由于逻辑分支问题也可能是 undefined 时，页面显示"NaN°C"。

根因：对 dailyTip 字段缺少防御性检查，temp 默认值逻辑不完善。

修复方案：对 tip.temp 做 Number() 转换并检查 isNaN，提供可靠的默认值。

状态：🔧 待修复

🟡 BUG-005 | 中等 | Clipboard API 在 HTTP 环境下静默失败

影响用例：C03, C04, E10

问题描述：navigator.clipboard.writeText() 在非HTTPS/非localhost环境下抛出异常但未被捕获，Toast 显示"已复制"但实际未复制成功。用户点击后以为已复制，实际粘贴板空空。

根因：Clipboard API 是 Secure Context API，HTTP 下不可用；代码用可选链 ?. 但没有 catch 错误和提供降级方案。

修复方案：添加 try-catch，失败时使用 fallback（选中文本 + document.execCommand('copy') 或直接提示用户手动记录）。

状态：🔧 待修复

🔵 BUG-006 | 轻微 | closeScenicDetail 不必要地重置搜索并重新渲染

影响用例：C24

问题描述：从景区详情返回列表时，closeScenicDetail 会清空搜索框并重新调用 renderScenicList()。如果用户之前通过搜索找到了某个景区，返回后搜索结果被清除，用户需要重新搜索。体验不佳。

根因：closeScenicDetail 中硬编码了搜索框清空逻辑。

修复方案：不清空搜索框，保留用户之前的搜索状态。

状态：🔧 待修复

🔵 BUG-007 | 轻微 | 管理端第二次打开弹窗时上次残留数据未清理

影响用例：A08, A17, A22

问题描述：编辑路线A → 取消关闭 → 编辑路线B。弹窗中可能残留路线A的 days 数据。这是因为 openRouteModal 读取的是 DB 中存储的数据（正确），但 window._editingRoute 可能还指向之前的对象。

根因：window._editingRoute 未在关闭弹窗时置 null。

修复方案：closeRouteModal/closeFoodModal/closeScenicModal 中增加对 window._editingRoute 的清理。

状态：🔧 待修复
